     - **What's wrong:** `$.process.run` runs in the session's cwd by default (typings :3406). With `-c`, Python puts the current directory first on `sys.path`. So a `struct.py`, `random.py`, `socket.py`, `email/` or `http/` in the user's project is imported in place of the stdlib.
